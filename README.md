# C++ Engineering Roadmap

Website tĩnh theo dõi lộ trình tự học C++ kỹ thuật. Không cần máy chủ, tài khoản hay bước build.

## Tính năng
- Lộ trình chia theo chặng và bài học.
- Ô tích lưu tiến độ trong trình duyệt bằng `localStorage`.
- Mỗi bài có nút **Học bài này với AI** tạo chỉ dẫn có ngữ cảnh: tên bài, mục tiêu, các bài đã hoàn thành và cách dạy ưu tiên thực hành.
- Có liên kết đến tài liệu C++ và website chạy code trực tuyến.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo một repository trên GitHub.
2. Tải `index.html` lên repository (ở thư mục gốc).
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/ (root)`, rồi lưu.
5. Đợi GitHub Pages xuất bản website.

## Tiến độ
Các ô tích được lưu bằng `localStorage` trên trình duyệt hiện tại. Nếu đổi trình duyệt hoặc thiết bị, tiến độ không tự đồng bộ.

## Tuỳ chỉnh
Nội dung lộ trình nằm trong mảng `stages` ở cuối `index.html`.
